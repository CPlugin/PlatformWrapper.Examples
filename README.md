# PlatformWrapper.Examples

> **Legacy, unmaintained.** These examples were written in 2017–2022 for a .NET
> platform wrapper library that is no longer distributed. The package they
> reference is not published on any public feed, so the solution does not build
> as is. The code is kept for historical reference only.

## Maintained alternatives

For new integrations use the hosted WebAPI at [mywebapi.com](https://mywebapi.com)
and its open-source client SDKs:

- .NET — [CPlugin/mywebapi.com-sdk-dotnet](https://github.com/CPlugin/mywebapi.com-sdk-dotnet)
- JavaScript / TypeScript — [CPlugin/mywebapi.com-sdk-js](https://github.com/CPlugin/mywebapi.com-sdk-js)
- Python — [CPlugin/mywebapi.com-sdk-py](https://github.com/CPlugin/mywebapi.com-sdk-py)
- PowerShell — [CPlugin/mywebapi.com-sdk-powershell](https://github.com/CPlugin/mywebapi.com-sdk-powershell)
